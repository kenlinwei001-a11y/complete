反馈回路（数据回流，使系统"成长"与"自洽"）

L1 数据构建发动机(FDE)：故事脚本 → comprehend(真LLM / 关键词地板) → 倒推写回【②数据 · ③本体/规则 · ⑤切片 · ⑥求解器需求】+ ⑧B栈(计划/意图/场景/Agent DRAFT) → 进启动器可推演（StoryBuildRun 留痕）
L2 自成长发动机(B)：客户问句 → 缺口探针(7码：NO_INTENT/NO_SLICE/SOLVER_NOT_FOUND…) → 补法【缺数据走真人正门② / 否则落施工工单】 → LOOP 重跑 → 收敛(可答)。成长账本+工单持久化
L3 校准回路：⑤时序实际 ↔ ⑥预测快照 → EMA/重放归因 → 回写⑥求解器参数(版本化,可重放回测)
L4 Action 真值写回：⑦审批后 EXECUTED → 回写④对象 props → 触发⑤二次派生 + 写回回声对账(同值抑制/异值告警)

横切关注点（贯穿每个模块的读写）

R2 多租户隔离所有仓储读写/事件/缓存键带 tenantId；跨租户一律 403/404
R3 Entitlement 门控功能关闭=不存在→404；先于 authz（feature 先判）
A6 行级过滤Policy 贯穿 query/slice/solver 读出；无权子树整条不出现
OutboxEvent → 前端失效任意产出(上传/发布/审批/tick)发事件；下游页订阅刷新(D-29, SLO≤60s)
