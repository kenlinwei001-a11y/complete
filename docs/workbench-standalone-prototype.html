配置

统一管理应急函数库、Agent、大模型、数据源与数据库、约束条件库与权限审计等系统配置能力。

应急处置函数库 · MCP 可调用

按 L1 场景域 → L2 能力层 → L3 原子函数 分层组织：每个函数有唯一 MCP 名称、带单位的参数 schema、可求值公式、关联资源域，以及“何时使用/何时不要使用/易混淆函数”，用于避免 Agent 调用时选错工具。

调用一致性校验

MCP 名称唯一性、公式变量与参数 schema 一致性、默认参数可求值、关联资源域是否存在于资源库、使用/禁用说明完整性。

整库 JSON / MCP tools 清单

左侧 JSON 可编辑保存（保存即权威）；右侧为按当前函数库生成的 MCP tools 声明，可直接注册。

函数库 JSON（可编辑）

MCP tools（只读，自动生成）

Agent 配置 · 按灾害场景

每类灾害对应专属 Agent：绑定大模型、配置 Skill、勾选 MCP 工具（来自应急函数库，按场景过滤避免误调）、挂接数据源（文件上传 / 连接器 / 数据库直连），并声明责任资源域。

大模型配置 · 多供应商

支持 Anthropic、OpenAI 兼容、Azure、阿里云百炼、智谱、DeepSeek、本地 Ollama 与自定义 HTTP 网关；每个供应商可配 Base URL、API Key 与模型清单，密钥以掩码保存、不回显明文。

数据源与数据库

按资源域分别接入数据库/接口/文件/连接器，字段映射到资源库口径（总量、可用量、预占量、存储位置），供 Agent 调用与资源库刷新。
