## §0 · 一页话

**我被要求独立判一次。第一件事就把 COO 的结论推翻了，第二件事把派单书自己的前提也推翻了。**

**一、COO 的四次对照，我一次不落全部重跑，数字逐位相同。然后我多跑了五次他没跑的，结论反转。**

他的结论是：**「墙是活的，它只随『按了几次』变，不随『扰了什么、多大』变。」** ——**这句话是错的。**

> 那个表单上「**起始拍**」这一格，**默认值是 `0`**，而世界已经跑到**第 3 拍**。
> **填 `0` 的扰动一次都不生效；填 `1`、`3`、`4` 全都生效，而且算得分毫不差。**
> 屏幕上**从不显示世界现在是第几拍**，按下去之后**也不告诉你这条扰动没生效**。

我把幅度拉成梯子，引擎的算术**精确到小数点后两位**：

| 起始拍 | 扰动 | supplyRisk | shortageRisk |
|---|---|---:|---:|
| **0（默认）** | supplyRisk 设为 **99999** | 5,496.22 | 3,819.70 |
| **0（默认）** | 预测偏差 **+10 / +100 / −100** | 5,496.22 | 3,819.70 |
| **4** | supplyRisk 设为 **50000** | **52,917.46** | **41,307.47** |
| **4** | supplyRisk 设为 **99999** | **102,916.46** | **81,306.67** |

**把最后两行相减**：supplyRisk 差 **49,999.00**，而我把幅度正好加了 **49,999** —— **误差 0**；
shortageRisk 差 **39,999.20** = 49,999 × **0.8**，而 **0.8 正是屏幕上那条边自己印着的系数**
（`Model.supplyRisk —model_demanded_by_order→ Order.shortageRisk 系数 0.8`）。

**⇒ 这台引擎不但读输入，还严格按屏上公示的系数算，误差为零。它被一个下拉框的默认值 `0` 关在门外。**

**二、派单书给我的两条前提，实测都不成立** —— 照铁律 0.6 第 5 条顶回来：

| 派单书写的 | 我实测 |

**而且它是我这两轮见过最好的一页** —— 但它**不在导航里**，只能靠手敲 URL 进去。

### 问三 · 沉没成本怎么算？扔、留、还是拆件？

**先把账算清楚，再下结论。**

〔仓〕**推演这一摊的资本分布**（我自己数的，不是抄的）：

| | 行数 | |
|---|---:|---|
| 后端推演引擎 `datacore/src/sim/` | **5,175**（10 个文件） | **这是唯一被证明算得对的部分** |
| 前端 `views/sim/` 合计 | **44,378** | LOOP4 我数是 56,018 ⇒ **已经砍掉 ≈11,640 行** |
| ├ 统一控制台 `views/sim/unified/` | 3,593 | |
| └ 沙盘及其余 | ≈40,785 | |
| 决策推演 `DecisionPlay*` | 1,945 | 不在导航 |
| **前端 : 后端** | **8.6 : 1** | LOOP4 是 10.8 : 1 ⇒ **在改善** |

**我的处置：拆件。** 而且拆法和 COO 的完全相反。

**为什么不是"扔"**：因为扔掉的会是**全系统唯一一台被证明算得对的机器**。
我今天拿到了本仓两轮以来**第一个可预言、可复算、误差为零的读数**：
`Δ幅度 49,999 → ΔsupplyRisk 49,999.00 / ΔshortageRisk 39,999.20 = 49,999×0.8`。
**这正是铁律 1.5 判据一要的那条对照实验，它今天通过了。**
统一控制台 3,593 行里，**真正坏的是一个默认值**。**为一个默认值扔掉一台通过对照实验的引擎，是我能做的最蠢的资本决定。**

**为什么不是"留"（原样留）**：因为它今天在导航里，**任何人按默认值用它都会得到假结论** ——
它不是不工作，它是**会骗人**。**一台会骗人的仪表，比一台坏掉的仪表贵得多**，
因为坏的那台没人信，会骗人的那台**有人信**（COO 就信了，而且信到写进裁决书）。

**拆件，具体拆法（三件，不许打包，不许扩编）**：

| 件 | 处置 | 理由 |
