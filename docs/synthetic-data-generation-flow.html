为什么"没配 LLM"也能生成符合场景的数据？

  • 合成不靠 LLM 编数据。数据的值全部由确定性 PRNG + GenSpec（区间/枚举/模板）产出，关系由 FK 一致保证。
  • LLM 只在"未知行业"时生成一次模板（结构）——有哪些对象类型/字段/规则；生成后存库复用，之后同样走确定性管线。
  • 已知行业（电池）用内置模板，整条链路零 LLM、零提示词；同 (行业,规模,seed) 重跑字节级一致（R6）。
  • 因此本流程只有一处提示词（②上方 TEMPLATE_SYSTEM，用途 template_gen）。comprehend（故事→建域）是另一条链路的 LLM，不在合成里。
  • 锚点：resolveTemplate(①/②) · mulberry32(③) · generateRelatedDatasets(④) · materialize(⑥) · runDerivations(⑦)。
