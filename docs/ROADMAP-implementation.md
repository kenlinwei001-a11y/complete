## 3. 关键纪律（贯穿全相位，来自 fde-delivery + ontology skill）

1. **绿测试 ≠ 能用**：每相位验收必须**以用户身份亲手从真实入口走一遍**，贴证据（截图/curl 响应），不拿单测/门绿冒充。
2. **断点在接缝**：分析/验收沿**链路**走（入口→QOS→计划→求解器→规则→渲染），不只看模块内部。
3. **绝不静默残缺**：任何缺口要么自动生长、要么诚实开工单+前端显示，禁止 fail-open 冒充已校验、禁止占位文案冒充答案。
4. **改接线必回写本体**：每相位末按表回写 `docs/SYSTEM-ONTOLOGY.md`，否则大脑过期。
5. **只推 `claude/vigilant-knuth-b1nmxn`**；模型标识不进任何提交物。
