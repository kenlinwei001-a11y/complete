# 六轨交付评审机制（防复发版 · 先设机制再开工）

> **为什么先设机制**：本项目反复栽在 **绿测试≠能用 / 文档与口头"全闭"虚标 / 自审盲区用错 oracle**。dev agent 现声称六轨"all complete / all closed / proven / 全闭"——**这正是历史上每次误判的同款措辞**（我自己也用它判错过"G-11 全闭""增量4 可合"）。故先钉死机制：**一切声称默认未验证，由独立真跑推翻或坐实。**

---

## 1. 铁律（违反即本次评审作废）

- **完成 = 我亲手真跑出该行为 + 证据**；**不认** dev 的 "tests green / FDE / proven / 全闭"。
- **Oracle = 该轨 HANDOFF 的 §1《源↔现状↔设计》追溯表里"该建的缺口" + §5 协议 + 红线**；**不是** dev 的 claims，**不是**我的旧设计印象。
- dev 说 **"planted-bug→红 proven"** → **我自己 plant 一个 bug 看是否真红**（不看他的测试绿）。
- dev 说 **"AC8 全控件无死路"** → **真浏览器逐控件点**（jsdom 测不出死按钮——G-4 教训）。
- dev 说 **"O9-O12 all closed / 自动 grow"** → **真跑 grow 一张缺件卡看是否真自动长成 GOVERNED**。

## 2. 三道关（dev 每个 bullet 声称逐条过，全过才该声称 ✅）

| 关 | 做什么 | 不过即 ❌ |
|---|---|---|
| **关1 真跑取证（FDE）** | 起真系统、以用户身份驱动该行为、截图/CLI/API 响应取证 | 只有测试绿、无真跑证据 |
| **关2 两轴核对** | 轴1：对源（HANDOFF §1 缺口 / 竞品 / PRD）逐元素；轴2：对设计逐元素是否真实现（非"渲染了就算"） | 任一源/设计元素缺 |
| **关3 红线专核** | 十红线 + 各轨专属（见 §4） | 任一红线破 |

## 3. 独立对抗验证（去自审盲 · 关键）

派**独立验证 agent，蒙眼对抗式**：读该轨 HANDOFF §1 + 真代码 + 真测试，**默认每条声称"未闭"，专找反例**——不看 dev 的 claims 措辞、不看我的旧判断。**重点查：是真实现还是桩/happy-path？测试是真证明还是套皮？标真实的有没有被重写？**

## 4. 各轨专属红线（关3 必核）

- **B 优化融合**：`THIRD-PARTY-NOTICES` 三红线——**不碰 Gurobi 示例 / 不把上游内容用作训练 / CDLA 只取派生 Results**；2-industry R14 须**同模板绑两本体零代码改**真出最优解。
- **C 数据构建发动机**：HANDOFF §1 标「真实」**13 项引擎主体没被重写**；E13 路由表去 `service.ts:79` 硬编码真生效。
- **D VLE**：V5 **参照实现真独立**（禁止 import 被测 `solvers/service`，第二套代码）；**我自己 plant 一个 bug 验 V11 真红**。
- **E 规则**：R9 的 11 求解器真出 PASS/WARN/BLOCK（非伪造尺度，口径不符诚实 NOT_APPLICABLE）；R10 **6 入口真跑改规则即改推演**对比。
- **F 场景发育**：**RL4 走正门**——grow **验证真出答案才 GOVERNED，不放水**；补不了诚实 PROVISIONAL+开票（别假装全闭）。
- **G 管理面**：AC8 **真浏览器逐控件点无死路**（非 jsdom）；引用控件 ＋新建/可查看三态齐。

## 5. 判定口径

- 逐声称 → **✅真闭（贴证据）/ ◐部分（列差）/ ❌虚标（列证）**。
- **全轨"可合"仅当该轨每个 bullet 声称个个 ✅ 带证据**；**任一 ❌ = 该轨打回**（列项+红线+建议）。
- **本体回写核**：F/G 声称回写 §8 G-9/G-10——核**回写准确不夸大**（◐ 别写成全闭）。

## 6. 棘轮（每抓一个虚标就收紧网）

每抓一个虚标 → 回写 `COMPLETION-LEDGER` 真跑判定 + 该类元素加进本协议标准检查表；凡 dev "全闭"被推翻 → 该轨打回 + 记教训。

## 7. 执行顺序

① **code-level 对抗摸底**（6 轨并行独立 agent，读 §1+代码+测试，逐声称标 real/stub/happy-path + **标出"必须我亲手真跑才能定"的项**）→ ② **我 personally 真跑关键项**（plant bug 验 VLE / 真浏览器走 AC8 / grow 一张缺件卡 / 改规则即改推演 / CP-SAT 两行业 / 发动机 runStory）→ ③ 逐声称判定 + 台账回写 → ④ 出**可合单 / 打回单**（逐轨逐声称）。

> 一句话：**dev 说什么不算数，我真跑出来什么才算数。六轨任一声称真跑不出 = 打回。**
