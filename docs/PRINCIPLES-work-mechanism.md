# 第一性原理

> 四条。每条底下挂着它**生成**的那一族规则 —— 记住根，那些规则就不用记。
> 样例全部出自 2026-09-18 当天实测。

---

## P1 · 证据和断言，必须指向同一个对象

本仓所有事故都能写成同一句：**「我用 X 当作 Y 的证据，而 X 并不度量 Y。」**
代理便宜、真相贵，所以人总在用代理。**每一次省下的那个往返，就是错误的入口。**

**它生成的规则**
- grep 到的串 ≠ 那个赋值存在（可能在注释里、字典里、别处的引用里）
- 台账说「没做」≠ 真没做；注释说「禁内联」≠ 真没内联
- 桥的四包全绿 ≠ 沙盘可以并（我要并的是另一个 commit）
- 否定结论必须配金丝雀 —— 「我没找到」和「它不存在」是两个命题
- **看与动分成两次调用** —— 同一条命令里既取证据又执行动作，证据来不及拦住动作

**样例**
> 清残留时我写了一条命令：先打印每个进程的 `cwd`，然后杀掉它们。
> 输出里写着 `cwd=agent-aaa39e4197dbce871` —— 一个**还活着**的 agent 的服务。我杀了它。
> 证据就在我眼前，和动作在同一次执行里。
>
> 同族：`cmd | tail; echo $?` 取到的是 `tail` 的退出码（本仓据此把**编译失败**判成「BUILD 通过」并入正线）。

## P2 · 缺口必须一直看起来是缺口

任何让缺口**看起来被填上**的东西，都会让它永久化。
因为缺口的修复压力，来自它**难看**；一旦它好看了，压力就没了，而缺口还在。

**它生成的规则**
- 算不出来 ⇒ 诚实失败，⛔ 不许 `COALESCE(…,0)` / hash / 默认值顶上
- 占位必须带**机器可判的关闭条件**，否则它就是永久的
- 指标必须有**期望值**：`0/7295` 是装饰，`0/7295（期望 7295 · 欠 7295）` 才是欠条
- 欠账报给**能修的人**（build / gate），不是报给用户屏
- ⚠ **「把教训写下来」也是一种填补** —— 它让问题看起来被处理了，而机器一个都没多

**样例**
> `实测格 0/7295` 一直亮在用户屏上和启动日志里，亮了几个月，没有任何人动。
> **不是看不见** —— 是它没有期望值（读的人无从判断 0 对不对），
> 且报给了改不了它的人（开发侧一条断言都没有）。
>
> 对照：`2480 passed / 0 failed` 你一眼就知道出事。唯一差别是**它有目标**。

## P3 · 实例 → 类 → 机器。停在前两步，就一定会重复

- 停在**实例**：修了这一个，下一个照旧 —— 而实例是无穷的
- 停在**类**：知道有多少，但没人守 —— 时间一长又长回来
- 到**机器**才算完：**下一个同类出现时，是机器先说话，不是人先想起来**

**判据（修完必问）**：**下一个同类出现时，什么东西会先说话？**
答不出「是机器」，就等于没修。

**样例**
> 同一天的两件事：
> · 给 45 个推演格接真值 + 盖出处章 ⇒ **停在实例**。只治了这 45 格，第 46 格照旧。
> · `compileSpecs` 加 dep 体检 ⇒ **到了机器**。下一条引用不存在属性的规格，
>   编译时当场判 `UNSATISFIABLE`，有名有姓，不依赖任何人记得。
>
> 而「数类」那一步我第 7 轮才做，**一条 grep**：hash 那支全仓 2 处。
> 在那之前我修了 45 格并宣布进展 —— **不知道分母就宣布进展，是最贵的一种自欺。**

## P4 · 出产方不能同时是验收方

我对自己的产出**没有鉴别力**。这不是态度问题，是位置问题 ——
判据是我定的，量法是我写的，我不可能用它去证伪我自己。

**它生成的规则**
- 重要结论必须先被**一个不知道我答案的人**量过
- 派单前提必须我**自己实测**，⛔ 不从别人报告里抄坐标（那是把别人的位置当成我的验收）
- 对照实验必须**带反向判据**：只有正向 = 空绿也能过
- 收编方与实现方分开；复验的头号判据是**亲手真跑**，不是读报告

**样例**
> 当天纠正来源：中立测量员 **5/5** · dev 实测顶回来 **3/3** · 仓主一句话 **4/4** ·
> **我自己读规则想起来 0**。
>
> 最狠的一次：我报「41/41 都是真实对象属性」（grep 出来的），
> 派一个不知道我结论的人去真起数据读 `o.props` —— **45 格，0 格读得到**，与我的结论完全相反。
>
> 另一例（反向判据）：一个 agent 的对照实验第一版是**空绿** ——
> 没喂 `pairWeights`，34 条边一条没触发，「目标边没动」差点被读成通过。

## 四条怎么连起来

```
遇到一个问题
 ├ P1 我手上这个证据，真的指向我要断言的那个对象吗？   ← 不是 ⇒ 先去拿真的
 ├ P3 同类共有几个？（一条命令）                      ← 不数分母不许宣布进展
 ├ P2 修法会不会让缺口"看起来"没了？                  ← 会 ⇒ 换修法
 ├ P3 修完谁先说话？答不出"机器" ⇒ 没修完
 └ P4 这个结论，有没有一个不知道我答案的人量过？       ← 没有 ⇒ 别报出去
```
