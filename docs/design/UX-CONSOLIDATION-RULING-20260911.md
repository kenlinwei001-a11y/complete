# ⚠ 盘点方自己点名的三个可能翻案处

1. **「谁会看见它」是按代码算的，没起服务验。** 若某处有租户级覆盖把收编开关关掉，**「归因与风险」整组隐藏、11 条收编项隐藏的结论会整体反转** —— 那时它们全部单列可见，是另一幅导航。**R5 直接依赖这一条。**
2. **「绑的求解器」被工具骗过三次**（字面量正则看不见常量传入的 key；闭包限在 views 漏掉共享件；闭包放开到全 src 则一条 endpoints 常量让 35 张屏全部误报）。**剩余风险最大的是「字符串键分发」** —— 驾驶舱的 5 个求解器全在后端布局的**数据**里，代码扫描结构上看不见。
3. **「服务哪条 COO 目标」是判断不是测量。** 最不确定的是图谱八视角：**若你认为「本体可视化本身就是全链路指标展示的一部分」，R1 的判定会整体翻转。**
