这一版新加的，只为「两个角色」这一件事：
① 排序尺换了 —— 第一层按越线日排，负荷率降为参照列。今天屏上按 severity 排， 而 severity 封顶 100（实测枣庄/常州双双 100），排名失去区分度。
② COO 独有「余量互补」一格 —— 单基地负责人看不到别人的余量，也就做不了跨基地调度；这一格只对 COO 有意义。
③ 两个角色共用同一份数据、同一套记号，只有口径与排序尺不同 —— ⛔ 不做两套算法，否则两个人对同一件事会拿到两个数。
④ 口径徽章在两屏都常驻：全网 与 本基地 一眼分得开 —— 今天实测传 baseId=changzhou 仍回 scope:"ALL"、首卡是江门， 而屏上一个字都看不出来。这是两个角色共用一块屏时最先炸的地方。
