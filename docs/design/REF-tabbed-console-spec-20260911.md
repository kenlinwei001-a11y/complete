## 图 1 · 「深度洞察」页

**壳层（三栏，左窄 · 中宽 · 右常驻）**

| 区 | 内容 |
|---|---|
| 左导航（深色、窄、图标+文字） | 品牌区两行（产品名 + 小字副标）· 9 个导航项（其中一项高亮选中）· **底部一个绿色主行动按钮**（「发起新分析」） |
| 顶栏 | 全局搜索框（居中偏右，placeholder 含具体检索维度）· 通知铃 · 用户区（头像 + 姓名 + 职称） |
| 右栏 | **常驻 AI 栏，不折叠、不弹窗、不覆盖内容** |

**中栏自上而下的节奏（这是最要紧的部分）**

1. **标题行** —— 大标题 + 一个**状态徽章**（「智能洞察」）；下一行一句副标说明；**右侧两个次级按钮**（「导出洞察报告」「自定义洞察」）
2. **页签行** —— 6 个：综合洞察 / 患者洞察 / 实验室洞察 / 研究洞察 / 预测分析 / 对比分析。第一个下划线高亮
3. **KPI 条** —— **5 张卡并排**，每张 = 标题 + 大数 + 「较上周 ↑x%」+ **一条迷你走势折线**（sparkline）。各卡用不同颜色区分
4. **右上角一块「本周关键发现」** —— 4 条带图标的要点 + 「查看完整发现 →」
5. **面板网格 · 第一行（2 列，左宽右窄）**
   - 左：**相关性热力图**（矩阵，红蓝发散色阶，右侧带色标 legend）+ 底部一行口径说明
   - 右：**AI 智能洞察** = 4 条卡片，每条 = 图标 + 标题 + **「置信度 xx% · 影响度 高/中」** + 「查看详情」按钮；底部「查看更多洞察 →」
6. **面板网格 · 第二行（3 列等宽）**
   - **环形图** + 图例（4 档分层，每档带人数与占比）+「查看细分详情 →」
   - **趋势预测折线**（历史 / 预测 / 置信区间三种线型）+ 右上下拉切换 +「查看预测详情 →」
   - **横向条形排行 Top 5**（带数值）+「查看所有驱动因素 →」
7. **底部元信息行** —— 数据更新时间 · 数据来源（N 家机构）· 样本量 · 置信度

**右侧 AI 栏的四段结构**

1. 栏头：标题 +「AI 模型在线 | 深度洞察模式」小字 + 右上 ⋮
2. **会话流**：AI 气泡 / 用户气泡交替；AI 气泡里是**带 ✓ 的要点列表**（每条后面跟一个括号量化值，如「（相关性 0.62）」）+ 「查看详细分析 →」按钮
3. **「建议下一步行动」块**：4 条带图标的清单 + 「生成行动计划 →」
4. 底部：输入框（附件图标 + 发送按钮）+ 下方 **3 个快捷 chip**（#深度分析 #关键洞察 #预测分析）+ 一个悬浮 **+** 按钮

## 从两张图里抽出来的 6 条结构规律（这才是「像这 2 个图」的所指）

1. **三栏固定**：左窄导航（图标+文字，底部一个绿色主行动）· 中内容 · **右常驻 AI 栏**。
   AI **不是弹窗、不是抽屉、不遮内容** —— 它和内容同时在场。
2. **中栏节奏固定**：标题行（含状态徽章 + 右侧次级动作）→ [可选页签行] → **KPI 条（3–5 张，每张必带 sparkline 与环比）** → 面板网格（先 2 列大块，再 3 列小块）→ 底部元信息行。
3. **每个页签是一套完整的、不同的 UX** —— 不是同一堆卡片换过滤器。图 1 有页签、图 2 没有，说明**页签是按"这是不是另一种看法"来切的，不是按"数据子集"**。
4. **深色主题 + 一个绿色作强调色**（主按钮 / 选中态 / 正向指标），红与黄专用于告警。
5. **每一块右下角都有「查看 X →」的下钻出口** —— 面板是入口不是终点。
6. **AI 栏四段恒定**：会话流 → 结论要点（带 ✓ 且每条挂一个量化值）→ 建议行动（带图标清单）→ 输入框 + 快捷 chip。
