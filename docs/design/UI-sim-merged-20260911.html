与今天线上版的差异（设计意图 · 不上屏）

  1. 并入沙盘的三样出口：导出报告 / 存为方案比对 / 收编为现状。今天控制台算完 18 处卡点、给了 4 套改法，没有任何一个按钮能把决定落下去——而这三样在沙盘里，且沙盘 UX 无法理解。
  2. 补上审批出口（区⑥ 第 6 步）。实测：决策推演 / 事件影响与对策 / 推演沙盘三页都有审批出口，唯独统一推演控制台为零。
  3. 时间一律用日期，不再写「第 N 拍」。往后 3 拍 → 2026-09-11 → 10-11（30 天）。换算所需的 tickDays 与 createdAt 本来就在会话上，后端零改动。
  4. 窗口可调，且把衰减写上屏。今天那句「一格都没改动」成立的前提是一个写死的 30 天窗口（冲击在窗口末端只剩第 3 拍的 1/31.6），而屏上一个字都没提。
  5. 已交付订单不计入敞口。今天涨价会同等推动 500 张单（含 350 张已完成），敞口因此虚报到 100%。修后为 147 张 / 28.2%。
  6. 客户按集团合并，可展开到法人主体。广汽三个主体分开看最大客户 33.3%，合起来 36.9%。
  7. 三行钱给出真数（毛利 / 成本 / 应收），系数取自规则 C15 登记参数与 BOM 用量占比，非内联常数。今天这三行一律「算不出来」。
  8. 卡点同名行加落点区分（磷酸铁锂正极 · 常州库 / 金坛库）。今天两行标签一字不差，分不清点的是哪一处。
  9. 「N 种改法」就地展开，选中态可见。今天点了它，面板在一屏之外（相距 997px），点第一项更是毫无反应。
  10. 全屏文案改台账语域：加一件或几件事，我算给你看 → 选择扰动事件；算 一 下 → 开 始 推 演；目标档位取自同侪对象上该属性的真实极值 → 同类产线已达到过。
