价值怎么定的

高 — 挂得到有金额有频次的经营场景，不做会直接少一个决策。订单簿总额 454.64 亿是场景敞口的基数。

中 — 影响数字的可信度或可解释性，但不决定能不能做决策。

低 / — — 追不到任何有金额的场景，或你已明确不做。

难度怎么定的

XS 改一处声明 / 加一个控件 · S 接一条已有的线（两端都在） · M 复用已有机制但要参数化或补数据源 · L 真要新建，会动数据模型或求解模型结构 · 0 已做完或已定不做。

⚠ 不报人天。人天是拍的，类别是查出来的。
