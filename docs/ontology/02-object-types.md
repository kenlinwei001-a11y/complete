> 借鉴外部开源优化推演项目（MIT）+ 行业 OR 模型数据集（CDLA-2.0）：**重写方法 + 派生产物 + 评测，绝不训练**。许可证红线见 `THIRD-PARTY-NOTICES.md`（LIC1 不训练 / LIC2 Gurobi 不碰 / LIC3 MIT 署名 / LIC4 CDLA 取派生），门 `solver-license:check` 守。落地规格见 `docs/SPEC-optimization-template-pool.md`（§14 接地核验为准）。增量 0 只立契约/本体/许可证，零求解器代码。

- **OptModelTemplate（抽象优化模板 · 全新，全代码库零命中）**：只认抽象 `(role, vtype, constraintFamily, 数值参数)`——无任何行业实体名（供应链/医疗/能源是绑定进来的内容，非代码）。9 初始 OR 核心族 `facility_location/min_cost_flow/set_cover/independent_set/assignment/scheduling/knapsack/packing/combinatorial_auction`（全 DERIVE：读懂结构→CP-SAT 重表达，非拷贝上游）+ `custom`。带 `provenance{derivedFrom,license}` 派生留痕（`solver-license:check` 校验）· 可扩展注册表呼应 `SOLVER_CATALOG`/`deriveOperationCatalog`，R16 离线进化器可长出 PROVISIONAL 模板。
- **StochasticMethodTemplate（随机模拟族模板 · 全新，全代码库零命中 · METHOD-MC-STOCHASTIC）**：抽象 `(uncertainFactors[{role,distribution,dispersionParamKey,clamp}], aggregate, percentiles[], iterations)`，零行业实体名（yield/oee 是**抽象角色**，绑定进来才成为某行业的 `Process.yield`）。与 `OptModelTemplate` 同居方法库、共用 `provenance{derivedFrom,license}` 派生留痕。内置 `capacity_mc`（`solvers/method-mc.ts BUILTIN_CAPACITY_MC`·平台内置只读）。**离散度不内联**：各角色变异系数 cv 落 SolverParam `mc.dispersion.*`（**可被 `CALIBRATION_SWEEP` 校准**——越用越准也调**方差模型**，非仅点估计）；`mc.iterations`(默认 2000)/`mc.staleDispersionMult`(默认 1.6·关键源陈旧→cv 放大→分布变宽→p90 下探·C09 诚实建模) 同落。契约 `packages/contracts/src/method-template.ts`（StochasticMethodTemplate/UncertainFactor/MethodBinding/McForecastResult）。
