### 根因（最后一处，已修）
  drill 里用的是裸 simAdvanceTicks —— 它**只写 sim_tick_state**，
  **不更新 session 的 curTick/status**（app.ts:2751 那段只有 putTickState）。
  而 GET …/world 是按 s.curTick 取 tick 态的 ⇒ curTick 停在 0 时**读到的永远是起点**。
  实测假象：E 的 tick state 里有 1..30 拍，而 GET /sessions/<E> 报 curTick=0 / status=READY
            ⇒「推演没发生」；连带 worldCellsMoved=1121 也不可信（它比的是错的 state）。
  修法：改用 tickSimSessionWorld（「真推 n 拍并落盘的**唯一实现**」）——
        它把 闸 + 规则 + 推演 + curTick + status + outbox 一次做全。
