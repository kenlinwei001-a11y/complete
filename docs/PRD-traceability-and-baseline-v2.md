## Part C · 最后两个算法缺口补全（公式级）

### C1 · `capex_scenario` 年度情景测算求解器（补 R14/年度情景规划台的算法层）

**输入**：情景需求曲线 `D[q]`（按季，万套）；产能项目集 `P_i = { 投产季 q0, 增量产能 cap_i(万套/季), 爬坡曲线 ramp_i[k]（投产后第 k 季系数，默认 [0.5,0.75,0.9,1.0]）, capex_i(亿，按季支出计划), 单位边际毛利 m_i(元/套), 残值率 }`；现有供给 `S0[q]`（=S1.2 月聚合×3 上卷）。

```
供给曲线   S[q] = S0[q] + Σ_i ( q≥q0_i ? cap_i × ramp_i[q−q0_i] : 0 )
缺口/过剩  G[q] = D[q] − S[q]          （连续 ≥2 季 G>0 = 缺口窗口；G<−5% S = 过剩窗口）
24月利用率 util24_i = Σ_{k=1..8} min(cap_i×ramp_i[k], 分配需求_i[k]) ÷ Σ_{k=1..8} cap_i×ramp_i[k]
           分配需求_i[k] = max(0, G_无i[q0+k]) 按各在建项目产能占比分摊（G_无i = 不含本项目的缺口）
项目现金流 CF_i[t] = −capex_i[t] + 边际产量_i[t] × m_i × (1−税率25%)   （t 按季，含末期残值回收）
IRR        使 Σ_t CF_i[t]/(1+r)^(t/4) = 0 的 r；牛顿迭代：r_{n+1}=r_n − NPV(r_n)/NPV'(r_n)，
           初值 0.1，收敛 |NPV|<0.01 亿，20 次不收敛报 IRR_DIVERGED（现金流全负等病态输入）
C23 判定   pass = (IRR ≥ 15%) ∧ (util24 ≥ 75%)        （阈值取规则库 C23 当前版本参数）
```

**输出**：三情景各自的 `{S[q], G[q], 窗口标注, 项目级 {irr, util24, c23pass}, 触发条件监测状态}`。情景触发条件为规则 DSL 表达式（如 `海外签约量 ≥ 80`），挂 RULE_SCAN 周期评估，命中→`scenario.triggered` 事件+升级动作记录。验收：构造单项目可手算用例，IRR 与解析值偏差 ≤0.1pct；病态输入报 DIVERGED 不死循环。

### C2 · 季度滚动供给口径（补 quarterly-rolling 数据端点的计算定义）

```
supply[q] = S1.2 月聚合上卷(q) + Σ已批准产能项目增量×ramp（C1 同源） + Σ该季 S&OP 决议增量
长协偏差   dev_m = (实际到货_m − 长协计划_m)/长协计划_m；|dev|>5% → 发 supply_risk 事件（关联到货间隙）
```

### C3 · S&OP 第④步财务整合口径（补 sop_balance 的计算定义）

```
毛利率_roll = Σ_seg(量_seg×价_seg×毛利率_seg) ÷ Σ_seg(量_seg×价_seg)     （细分价/毛利率取应用细分对象）
现金垫     = min_{w∈1..13}( 期初现金 + Σ_{k≤w}回款[k] − Σ_{k≤w}付款[k] − Σ_{k≤w}CAPEX支出[k] )
            回款[w] = Σ 应收按账期(T+60 默认)到期额；付款[w] = Σ 采购按账期到期额
④门禁     毛利率_roll < 预算−0.5pct → 警示进⑤议程；现金垫 < C18 底线 → 阻断进入⑤
```
