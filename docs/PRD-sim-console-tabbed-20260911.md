## 0 · 两条必须先裁的前置（绕不过去）

### 前置 A · 页签式与不变量 R17「决策单页」冲突

本体 §5 **R17** 原文（前端宪法）：

> 决策页**一页看全** 数据→推演→溯源→动作→AI，**就地下钻不跳页**、配置驱动密度。

而本稿是**七页签、每页签不同 UX**。两者不能同时成立。三条出路，**必须选一条**：

| | 做法 | 代价 |
|---|---|---|
| **A1** | **修订 R17**：把「一页」的粒度从「一个页面」降到「**一个页签**」——每个页签内部仍然一页看全（本稿右侧常驻 AI 栏 + 就地下钻正是这个形态） | 要回写本体 §5，且 R17 配套门 `decision-page:check`（本体标「待建」）的判据要跟着定 |
| **A2** | **放弃页签**，回到单页 | 仓主已否掉瀑布稿 |
| **A3** | **给推演控制台一条 R17 例外**并写明理由 | 例外会被后来的人当先例，本仓有「豁免被例外吃光」的账 |

**建议 A1**，理由：参考图那两屏本身就是「每个页签一页看全」，R17 的**意图**（不跳页找答案）在页签式下并未被破坏，破坏的只是它**字面**的「一个页面」。
⛔ 但这是**本体条文修订**，属产品治理决策，PRD 不替仓主定。

### 前置 B · 新增 entitlement 键触碰禁令 3

### WO-2 · 推演金额的诚实位（关闭 `G-DATAMODE-PROV` 金额侧）　【最高优先】

- **今天的行为是 X**：种子世界 t0 加权 `costPressure` = **49.62 是哈希占位**（`measuredCells:0`），tick3 = 93.10 ⇒ 毛利绝对投影 **−422.12（−455%）**；而回包**没有一格**披露基线是派生占位（`measured/derived/hash/占位` 全 payload 零命中）。
