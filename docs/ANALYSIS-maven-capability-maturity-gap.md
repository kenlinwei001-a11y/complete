# 分析 · 照 Maven 能力清单对标本系统「距成熟决策支撑系统还差几环」

> 用户问：照 Palantir Maven（Maven Smart System）的能力模型，逐条对本系统、列出距离一个成熟决策支撑系统还差什么。
> 审核方按 Maven 式"多源融合→本体→AI 推理→人机决策→行动闭环→审计/治理"能力模型拆 14 环，逐环对照本系统**本会话真跑/读源所得状态**（非纸面）。评级：✅成熟（Palantir 同级）/ ◐大部（有裂缝）/ ❌明显缺。

## §2 综合判断

**骨架是 Palantir 级的，缺的是"让数据活起来 + 让人机决策接地 + 生产扛得住"。**

- ✅ **真成熟（3 环）**：本体语义层(2) · 权限多租户(10) · 治理审计(9)——这是 Palantir 的看家本事，本系统做到了同级。
- ◐ **大部但有信任裂缝（3 环）**：数据置信度(3) · 行动闭环(8) · 可扩展(13)。
- ❌→◐ **距成熟最该补的 5 环**（= 本会话发现的核心 gap，**和已立 WO 一一对应**）：

| 缺的环 | 一句话 | 主 WO | 为何是命门 |
|---|---|---|---|
| **A 多源/时序态势** | 推演只吃订单一维、紧张度是哈希 | WO-FORECAST-SIM | 决策系统的"态势感知"地基；Maven 的灵魂就是多源融合 |
| **B 置信度诚实位** | hollow-data 冒充真算 | WO-DM | 决策系统的**信任命门**——假数据驱动的决策不可信 |
| **C 场景接地对话** | 对话入口未配置完整 | WO-SCENE-* | 人机协同决策的入口；现在"问不出接地答案" |
| **D 生产/多实例韧性** | PG/重启/构建一连串坑 | WO-T5-RESUME-LEASE/GATE-B | "实验室绿、生产挂"——决策系统必须生产扛得住 |
| **E 学习+沙盘活体** | 越用越准/what-if 未成日常 | M11 活体/沙盘 | 成熟系统的"自进化"闭环 |

> **关键结论**：**本会话排出的 WO 队列，本身就是这份"距成熟还差几环"的路线图。** 优先级也对得上——A/B/C 是 P1（态势+信任+决策入口）、D 是 P0/P1（生产韧性）、E 是中期。不是另起炉灶，是把已发现的 gap 按 Maven 能力模型重新组织成"成熟度地图"。

## §3 诚实边界

- Maven 是**军事 ISR/目标系统**；本对照只取其**能力模型/工程模式**（多源融合/本体/HITL/审计/闭环），**用途无关**（本系统民用工业决策）。不涉任何 targeting/武器能力。
- 评级基于**本会话真跑/读源**（标 ✅）+ 本体登记（标 ◐）；非全量穷举，是审核方架构判断。military "密级分层/实时传感器流"等军用专属环按民用语义折算或标注不适用。
- 本体引用：链路 `sys.orch.query_to_answer`（决策链）/数据→本体→推演链；不变量 R4(行动经审批)/R13(溯源诚实)/R2-R3(隔离/门控)/R14(跨域)；断点 G-5/G-9/G-11 + hollow-data + P0-LOCK。
