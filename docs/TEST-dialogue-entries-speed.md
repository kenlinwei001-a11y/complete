> 给测试 agent：本项目"问问题"的入口不止一个。本文档列**所有人机对话入口**，每个入口给**不同类型的问句**，并把**速度**当一等指标测（头号坑：有对口求解器的定式题被误送进慢 agent）。

## 0. 前提

1. **起服务**：`docker compose up --build`（首启播种等 ~8–10 分钟·datacore healthy 后 gateway 才放行）。开 http://localhost ，登录 **demo / admin / demo1234**。
2. **绑真 LLM（path-B 必需）**：admin → LLM 供应商 → 加 `openai_compatible`（base `https://api.moonshot.cn/v1`，key=你的 Kimi，model `kimi-k2.5`）→ 路由 `agent`/`classifier` 角色到它。
   - **不绑**：path-A 确定性题仍可测（秒级）；path-B 会诚实降级（"未接入 LLM"·瞬回），**测不出真 agent 速度**。
3. **DRIL 已点亮**（demo·`qos.dril-routing`），path-B 首轮会注入资源包。

## 1. 怎么量速度（每题都记）

- **秒表口径**：从**点"发送/提问"**到**答案完整呈现**（SSE `task.completed`）的墙钟秒数。
- **精确口径**：`GET http://localhost/api/v1/queries/<taskId>` 看 `createdAt`→`completedAt` 差；或浏览器 DevTools → Network 看 `POST /api/v1/queries` 后 `…/events` SSE 流持续时长。
- **路径判别**：答案卡/任务详情里看 `path`——`A`=确定性求解器，`AGENT`=path-B ReAct，`COMPOSE`=多 solver 组合。

### 速度基线（判过判不过的尺子）
| 路径 | 触发 | 期望速度 | 上限 |
|---|---|---|---|
| **path-A**（确定性 solver） | 有对口单一 solver 的定式深问（高置信 ≥0.6） | **秒级（≤3s 常见）** | 单 solver 15s |
| **path-B**（LLM ReAct·DRIL 注入） | 真开放/跨域/假设题 | 数十秒·**round-trip≤4** | 单次 LLM 60s |
| **降级**（无 LLM/预算尽） | provider 未绑 或 预算耗尽 | 瞬回诚实降级文案 | — |

> **头号测速判据（回归护栏）**：**"有对口 solver 的定式深问"必须走 path-A 秒级**——若这类题显示 `path=AGENT` 且耗时数十秒，就是**误降级到慢 agent**（病根回潮），判**不过**。

## 3. 逐入口测试用例（不同问句 + 速度）

> 每条记：`path=?`、耗时秒、答案是否带 ⟦ref⟧ 溯源、判过/判不过。

### E1 · 全局问答坞 QueryDock（最主入口·所有页可用）
在任意页对话坞依次问以下 **4 种不同类型**，重点看**路由分流 + 速度**：

| 编号 | 问句 | 期望路径 | 期望速度 | 判过 |
|---|---|---|---|---|
| E1-a | **储能份额为什么下降，逐层拆到根因** | path-A（gap_attribution 秒答） | **秒级** | path=A + 秒级 + 逐层归因带 ⟦ref⟧ |
| E1-b | **4680-NCM 加 20% 六周能不能接** | path-A（capacity_feasibility） | **秒级** | path=A + 秒级 + 给可行/缺口结论 |
| E1-c | **综合评估储能份额下滑的连锁影响，该怎么补** | path-B（真开放·DRIL 注入） | 数十秒·rt≤4 | path=AGENT + 首轮注入【DRIL 智能资源包】+ 一步调对口 solver + ⟦ref⟧ |
| E1-d | **如果盐城限电两周，对全局交付有什么影响** | path-B（假设推演） | 数十秒 | path=AGENT + 不空转 + 诚实标不确定处 |

**E1 头号判据**：E1-a / E1-b **必须 path-A 秒级**（不得 AGENT 慢答）；E1-c/d 走 AGENT 但 round-trip≤4（DRIL 生效）。

### E2 · 驾驶舱块级 CEO 深问（4 块 · 带页面上下文）
在 Dashboard 各块点"问一问"，问句带该块上下文，验**上下文注入 + 确定性优先门**：

| 块 | 问句 | 期望 | 速度 |
|---|---|---|---|
| 供需失衡块 | **这块缺口主要是需求端还是供给端造成的** | path-A·gap_attribution·秒级 | ≤3s |
| 根因树块 | **把这个根因再往下钻一层** | path-A·逐层·秒级 | ≤3s |
| 指标条块 | **哪几个经营指标没达标，差多少** | path-A·metric_rollup·秒级 | ≤3s |
| 反事实块 | **如果这个因子回到基线，结果会怎样** | path-A/COMPOSE·派生 what-if | ≤5s |

**E2 判据**：块上下文让确定性优先门命中 → **秒级 path-A**；答案数字都带 ⟦ref⟧；改块选中项再问 → 输出真变（非写死）。

### E3 · 场景启动器
点首屏 3–5 张场景卡各一次 → 应进对应视图并**自动带入预置问句真跑**（非静态占位）。判过：进页即有真答案/真推演，不是空壳。

### E4 · 全局联合推演·活①人机对话（GlobalSim）
| 编号 | 问句/操作 | 期望 | 速度 |
|---|---|---|---|
| E4-a | 活①NL 框：**把常州订单优先保交，看整体交付率变化** | compose/portfolio 真重解 | 数秒~十几秒 |
| E4-b | 活②自由杠杆：拖动某杠杆（夜班/加产）→ before/after 七维 KPI | 后端真重算·真变 | ≤5s |
| E4-c | 勾选业务类型（乘/商/储）子集再推演（若已上线 W5） | 只对勾选集重解·矩阵真变 | ≤5s |

**E4 判据**：改问句/杠杆/勾选 → 矩阵/KPI **真变**（前端假过滤会露）；窗口标注 = **14 天**（不是 21）。

### E5 · 沙盘 Sandbox（QueryDock + tick）
问 **"推演如果某供应商断供两周的传导影响"** → init→tick→观察跨对象传导。判过：tick 真跨对象传导（非静态），答案带溯源。

### E6 · 项目推演 what-if
问 **"这个项目分批交付 vs 一次交付，交期和成本差多少"** → 分批模式六步 stepper + DAG。判过：改分批参数→wkEff/物流时长/交期真变。

### E7 · 决策推演多方案
问 **"给我 2–3 个接单方案并比对触发行动"** → 多方案候选 + 比对 + 可触发 Action。判过：≥2 方案 objectiveValues 真漂移，非写死。

### E8 · 风险看板/产能活台
块级问 **"这个基地的产能风险根因是什么，怎么处置"** → 归因过程可见 + 处置方案区。判过：出过程非只结论；灰节点（物流时长/设备OEE）诚实标"合成·未接实测"不冒充实测。

### E9 · 产销重排/计划审计
问 **"把这批订单重排到最优，交期优先"** → sop_reschedule/portfolio。判过：走对口 solver（不心算），给重排方案带溯源。

## 4. 速度专项汇总（跑完填）

| 入口·题 | path 实测 | 期望 path | 耗时(s) | 期望 | ⟦ref⟧? | 判定 |
|---|---|---|---|---|---|---|
| E1-a 储能份额拆根因 | | A | | 秒级 | | |
| E1-b 4680 加20%六周 | | A | | 秒级 | | |
| E1-c 连锁影响怎么补 | | AGENT | | 数十秒·rt≤4 | | |
| E1-d 盐城限电假设 | | AGENT | | 数十秒 | | |
| E2 供需块深问 | | A | | ≤3s | | |
| E4-a 优先保交 | | COMPOSE/A | | 十几秒 | | |
| E7 多方案比对 | | AGENT/A | | | | |

**总判定**：
1. **确定性题（E1-a/b、E2 全部）秒级 path-A** —— 任一变 AGENT 慢答 = 误降级回潮 = **红**。
2. **开放题（E1-c/d）path-B 且 round-trip≤4**（DRIL 注入生效）—— 十几跳盲扫 = **红**。
3. **每个业务数字带 ⟦ref:N⟧ 溯源** —— 裸数/编数 = **红**。
4. **改输入→输出真变**（E2 改选中/E4 改杠杆）—— 不变 = 写死 = **红**。

## 5. 范围与已知边界（别误判为 bug）
- path-B 速度依赖真 LLM；未绑 provider 时 path-B 瞬回诚实降级（不是"快"，是没跑 agent）。
- 首启 8–10 分钟播种期 gateway 502 属正常。
- 灰节点（物流时长/设备OEE）诚实标"合成·未接实测"是**设计如此**（KILL-MOCK），不是缺 bug；其自动补齐属下一轮。
- W5 业务类型勾选（乘/商/储）若尚未并线，E4-c 可能不可见——不算回归。
