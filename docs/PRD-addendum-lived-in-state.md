# PRD 增量 · 运营态出厂配置（"拎包入住"：登录即呈现已运行一年的系统）

| 项 | 值 |
|---|---|
| 版本 | v1.0（增量：扩展 A7 合成数据 §7.2 与 A8 模拟时钟 §6；新增"出厂配置基线"与"一年运营态"验收口径） |
| 需求 | 交付物不是"待配置的空平台"，而是**登录即用**：数据、逻辑、agent 对每个前端场景入口全部预配置；系统呈现"已运营 12 个月"的状态——有历史、有痕迹、有精度收敛证据，用户与销售零配置直接使用 |
| 核心原则 | **运营态是"生成+回放"出来的，不是画出来的**：确定性生成 12 个月源头事件流 → 真实管线（聚合→派生→规则→校准）回放计算 → 任何数字下钻溯源都成立、跨模块天然一致、同 seed 字节级可复现 |

## 1. 运营态种子引擎（扩展 A7/A8）

### 1.1 初始化回放机制
合成任务新增 `livedIn: true` 选项：模拟时钟从 **T−365 天**起以日粒度连续 tick 至 T0，沿途执行**年度剧本**（§1.3），每个 tick 走 A8 §6.2 全链（源头数据→聚合→派生→规则扫描→校准配对）。回放完成 = 一年运营态就位。性能要求：S 规模全量回放 ≤ 5 分钟（增量聚合是前提）。

### 1.2 生成的源头记录清单（规范性，量为 S 规模默认值）

| 记录 | 量 | 关键叙事要求 |
|---|---|---|
| 订单生命周期 | 已交付 60 + 在手 20 | 状态机完整（创建→排产→生产→交付）；**9 单曾延期、其中 7 单因采纳处置方案挽回至 ≤2 天**——延期与挽回必须与对应风险案例/Action 记录互相引用 |
| 生产实绩/OEE 时序 | 12 基地 × 365 天 | 全年爬坡（0.86→1.0）；各基地年度检修月产出可见下凹，且与本体检修计划对象同月 |
| 告警-处置闭环案例 | 10 例 | 每例完整链：越线日→采纳方案（关联 Action）→曲线消解→受影响订单清单；前端风险视图"历史处置案例"区直接消费 |
| Action 审计史 | 200 条 | 状态分布约 82% EXECUTED / 11% REJECTED / 4% CANCELLED / 3% EXECUTION_FAILED；**被拒记录必须带像样的审批意见**（如"外协贴近 C08 红线，改用夜班方案"）——拒绝痕迹是真实感的关键 |
| 任务/对话史 | 每场景入口 2–6 条 | 预置历史问答（问句+回答+信任级+日期），前端对话框按场景预载为半透明历史区 |
| S&OP 版本史 | V1–V12 | 每月需求/供给/达成率/第⑤步决议；达成率从 88% 爬至 94%；与月度实绩同源勾稽 |
| 校准叙事 | MAPE 52 周序列 + 8 次提案 | **MAPE 12%→7% 指数收敛**，第 21–22 周因 Q4 到货危机回弹 +1.8pct 后继续收敛；8 次提案含 **2 次被拒**（一次触发结构性漂移闸门、一次回测改善不足 1pct）——按 M11 增量的真实方法标注 method 字段 |
| 规则版本史 | ≥5 条 | 如 C08 v1.0(≤25%)→v1.3(≤20%)，每版变更附复盘原因；C16 覆盖天数 3→5 天挂"到货危机复盘" |
| 意图孵化记录 | 3 条 | 标注"由兜底问题《…》×N 次孵化于某月"——演示运营闭环真实发生过 |

### 1.3 年度剧本（scenarioScript 出厂版，构成叙事弧线）
Q1 产能爬坡期（MAPE 高、校准频繁）→ Q2 检修季（各基地错峰检修、OEE 下凹）→ Q3 需求上修（储能占比抬升、C21 差异提报入 S&OP 议程）→ **Q4 到货危机**（正极延迟→风险越线→采纳备料方案→消解；精度冲击与回弹；C16 规则因此收紧）→ 年末稳定运行。剧本事件之间必须互相引用（危机→规则变更→校准回弹→订单延期挽回是同一事件的四个侧面）。

## 2. 每场景入口出厂预配置（零配置清单）

| 场景入口 | 模式 | 绑定 | 预置内容 |
|---|---|---|---|
| 经营驾驶舱 dash | WORKFLOW_FIRST | 意图全集 | 12 个月产出趋势图、准交率 KPI、已交付台账、历史问答 ×2 |
| 产能推演 risk | WORKFLOW_FIRST | affected_orders / risk_root_cause / adopt_mitigation | 历史处置案例区（10 例）、历史问答 ×2 |
| 项目推演 project | WORKFLOW_FIRST | capacity_feasibility | what-if 默认参数、历史问答 ×1 |
| 规划体检 audit | **WORKFLOW_ONLY** | plan_audit_q | 基线=最近定稿 S&OP 版本、历史问答 ×1 |
| 规划建议 generate | WORKFLOW_FIRST | plan_recommend | 默认目标面板、历史问答 ×1 |
| 自由探索 explore | **AGENT_FIRST** | agent=analyst | 建议问题、历史问答 ×1（AGENT 信任级样例） |
| 运营回顾 review | WORKFLOW_FIRST | （只读历史） | §4 运营回顾视图全量 |

每入口的 agent/workflow 选择、建议问题、历史问答全部在场景包种子内——**用户登录后无任何"先去配置"动作**。

## 3. Agent 出厂配置

1. 默认 `analyst` agent：成熟系统提示词（数字红线/写降级/能力边界/注入防护四要素）、scopeDeclaration、预算——出厂即过 QOS-PRD §12 验收；
2. **经验记忆库种子 50 案例**：从回放期的任务史自动沉淀（问句+解法+结果），路径 B 检索可命中——"越用越聪明"出厂即有底料；
3. 团队优化界面 = 管理台 agent 编辑器（既有 PRD），出厂配置是起点不是锁定。

## 4. 前端落点（修订前端 PRD）

1. **驾驶舱**：新增 12 个月产出趋势（检修月下凹可见）、准交率 KPI、年度已执行工单数、已交付订单台账；
2. **新增视图 `review` 运营回顾**（renderer 复用 dashboard 类）：MAPE 收敛曲线（标注危机回弹点）、参数校准史表（含被拒及原因）、S&OP 版本史、Action 审计史（分页）、规则演进、意图孵化记录——**"越用越准"的证据链页面**；
3. **风险视图**：追加"历史处置案例"区（越线→采纳→消解，案例点击可回放当时的时序曲线）；
4. **对话框**：按场景预载历史问答（半透明+日期+信任级徽章），分隔线"以上为历史问答"；
5. 全局：合成运营态水印徽章（hover 显示 generatedFrom 与 seed），与 A7 §7.2 的 SYNTHETIC 标记联动。

## 5. API 契约（DataCore 新增）

```
GET /a/v1/history/bundle    → { trend[], monthly[], delivered[], deliveredCount, onTimeRate,
                                riskCases[], actionHistory[], mapeSeries[], calibrations[],
                                sopVersions[], ruleVersions[], incubated[], taskHistory[], generatedFrom }
```
行级权限同样作用于历史：基地维度记录按 visibleBases 过滤（czmgr 只见常州的月度/案例）；Action/校准等租户级记录全量。大体量子集（actionHistory 等）支持分页参数。

## 6. 真实部署的替换路径（FDE 交付口径）

合成运营态定位为**售前/POC/培训环境**。真实部署后：连接器接入真数据 → 真历史按月回填覆盖同期合成记录（origin 字段区分 SYNTHETIC/LIVE）→ 由于一切走同一管线，前端与推演无感切换；水印随 LIVE 占比消退。**禁止**在生产租户混用合成与真实记录而不带 origin 标记。

## 7. 验收标准（"一年感"检查清单，全部自动化 + 1 项人工）

| # | 用例 | 预期 |
|---|---|---|
| Y1 | 新租户 livedIn 合成 → 登录 | 7 个场景入口全部有数据有历史，**零配置动作**；S 规模回放 ≤5 分钟 |
| Y2 | 同 seed 重放 | history/bundle 全量字节一致 |
| Y3 | 三层下钻不穿帮 | 任取驾驶舱月度产出 → 基地月度明细 → 当月检修事件，三层数字同源且检修月下凹与检修对象同月 |
| Y4 | 叙事互引 | Q4 危机的 风险案例/Action/规则 C16 变更/MAPE 回弹 四处记录相互引用同一时间窗 |
| Y5 | 延期挽回链 | 9 单延期中 7 单的挽回备注关联到对应处置案例与已执行 Action |
| Y6 | 行级权限作用于历史 | czmgr 的 bundle 仅含常州月度/案例；准交率等聚合按可见范围重算 |
| Y7 | 校准证据链 | MAPE 序列收敛 + 2 条被拒提案带方法学原因（漂移闸门/回测门槛） |
| Y8 | 对话历史预载 | 每场景历史问答渲染且信任级徽章正确 |
| Y9 | origin 替换 | 模拟接入一个月 LIVE 实绩 → 同期 SYNTHETIC 被覆盖、趋势图无缝、水印比例变化 |
| Y10（人工） | FDE 盲测 | 不知情评审员使用 10 分钟后回答"该系统已运行多久"——预期答案 ≥ 半年 |
