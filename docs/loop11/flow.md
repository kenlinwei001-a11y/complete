首页并列 **12 个**推演类入口（统一推演控制台 / 沙盘 / 指控台 / 传导识别 / 损失归因 / 方案寻优…），

题目要的物料延期 / 产线停机 / 客户砍单**一个都选不出来**。
（金丝雀：同平台推演沙盘同类控件 **100 项落点、41 个状态变量** ⇒ 枚举可用，
是**这一屏没给**，不是数据没有。）
