## 1. 实测「真的用一遍」（铁律 0.4·非复验我自己的功能，而是复验"用户能不能用"）

真起 datacore(SEED_DEMO=1)+agentcore·真登录 admin·真开 /v/sim-sandbox·**真的当用户用一遍**：

| 动作 | 实测结果 | 用户感知 |
|---|---|---|
| 打开沙盘 | 认证恒 `L1_CONFIGURED`·顶部大字 **"✗ 暂不可进入推演"** | "这页打不开/用不了" |
| 推进 1 tick（`POST /sim/sessions/:id/tick`） | HTTP ok·curTick+1·但**基地(Base)对象态 `{}` 空**、样本对象态全 0（demandDelta/demandLoad/loadIndex/totalDemand/utilization 全 0） | "推了没反应·死的" |

**结论：页面 out-of-box 不可用**——认证门挡住"进入推演"的感知，且**无输入驱动 → 静止零世界**，推演推了等于没推。这正是用户说的"不可用"。

## 2. 根因（沿链路走·断点在接缝·非我前端渲染域）

实测 demo GLOBAL cert：`trialTick.passed=true`(3 规则触发)·`worldCompleteness=100%`(状态变量 11/11·派生 11/11·行动 12/12·传导 3/3)·
`l4Checks{fanoutSafe✓ writebackComplete✓ observabilityMet✗}`·`gaps`：
- **前向闭合 3 条 HARD**：`FORWARD rule:C24->Quote / C45->Action / C50->Action —— 规则 scope 类型缺失`。
- **图查询覆盖 1 条**：`GLOBAL 图查询覆盖 40/43 对象·切片 48 < minQueries 1` → `observabilityMet=false`。

`canEnterSimulation = L4 ∧ trialTick.passed ∧ closure.gatePassed`。closure 有 3 条 FORWARD HARD → 门不过 → 级别压 L1 → 永不可进入。

**根因三层（全不在前端渲染域）**：
1. **本体前向闭合缺口**（数据/建模域·Dev-1 或数据闭合单）：3 条规则引用的 scope 对象类型未定义/未归域 → closure 门恒红。
2. **out-of-box 无输入场景**（数据/产品）：baseline 无 shock/无外生驱动 → 传导目标(Base.loadIndex/Model.demandLoad)态空、推演静止零。**引擎能跑**（S1 已证 shock→传导真跑），但**开箱没有一个"有输入、能出有决策意义结论"的默认场景**。
3. **认证门产品定义**（产品/前端交互）："暂不可进入推演" 是**硬挡感知**——即便机制上能推 tick，用户看到大字"不可进入"即判定不可用。

## 4. 建议 root-cause 单（做这些才叫可用·全局最优·多数非前端域）

按"让用户开箱能真跑一次有决策意义的推演"倒推，优先级从高到低：

- **RC-1（数据/本体闭合·Dev-1 或数据域·最高优先）**：关闭前向闭合 3 条 HARD（C24->Quote/C45->Action/C50->Action 的 scope 类型补齐/归域）
  + 图查询覆盖 40/43→43/43，使 `closure.gatePassed=true`、`observabilityMet=true` → 认证可达 L3/L4 → **"可进入推演" 真能亮**。
- **RC-2（数据/场景·数据或 Dev-1 域）**：沙盘 out-of-box **载入一个有真输入的默认场景**（如"常州二线 load +20 冲击"种子），
  打开即见非零传导、推 tick 有真变化——**开箱即可用·非静止零**。（引擎已就绪·缺的是默认输入。）
- **RC-3（产品/前端交互·我的域可承接）**：若产品意图允许"未认证也可试跑"，把认证门从**硬挡**("暂不可进入推演")改为
  **"未认证·可试跑·结论仅供参考"**——让用户在闭合未齐时仍能进去推、拿到带诚信位(S2)的参考结论；否则用户永远进不去。
  **这是前端能立即承接的一单**（与 S2 诚信位天然协同：试跑结论全打 UNCALIBRATED/来源待披露）。

**判据（做完才算可用）**：admin 开沙盘 → 不点任何配置 → 能进入/试跑 → 推 tick 见基地态真变 → 拿到一条有决策意义的结论（哪怕标"仅供参考"）。当前四步全断。
