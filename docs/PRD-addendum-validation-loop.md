## 1. 验证闭环的七段定义

```
A9 GenSpec（真值已知） 
 → ①接入（A1 连接器/A8 时序通道）        断言：行数/字段画像/隔离区分流
 → ②建模与对象化（A3→A4）               断言：对象数/血缘/引用完整性
 → ③聚合与派生（A8 聚合→A4 派生管线）    断言：快照属性与派生值 vs 解析期望
 → ④规则（A5 求值与持续监测）            断言：注入的违规被全部命中、无误报
 → ⑤推演（求解器 + QOS 双路径）          断言：求解值 vs 参照实现；路由/溯源/降级行为
 → ⑥行动（Action→审批→写回→回声对账）   断言：状态机终态/审计链/回声打标
 → ⑦校准（M11：偏差→提案→应用）         断言：提案方向与幅度 vs 注入偏差的解析解
 ↑——————— 模拟时钟逐日推进（回放编排器驱动②–⑦循环）———————|
闭环判据：⑦的提案被（虚拟审批）应用后，⑤的后续预测 MAPE 实际下降——系统自证其学习回路有效
```

## 2. 真值预言机（Oracle，三类，实现必须独立于被测代码路径）

| 类 | 原理 | 例 |
|---|---|---|
| **构造真值** | GenSpec 声明了分布/行数/因果注入，期望值解析可算 | 接入行数=Σcount；OEE 日均值期望=base.mean×季节系数（容差=3σ/√n）；检修窗内产出凹陷幅度=注入 magnitude |
| **参照实现** | 关键公式在验证包内由**第二套独立代码**实现（禁止 import 被测模块——静态检查强制），双算比对 | capacity_forecast 的 P50/P90、IRR、plan_audit 评分、风险时序逐日值、派生金字塔 |
| **不变量** | 与具体数值无关的守恒律 | 驾驶舱聚合 == 明细求和；任意 provId 可解引用且重算同值；权限视图 ⊆ 全量视图且零越界；同 seed 全链重放逐字节幂等；epoch 单调；派生二次重算不动点；审计表只增不改 |

| 段 | 模块 | 断言点（抽样列举，完整清单随实现登记进 VLE 注册表） | Oracle 类 |

## 4. 执行模型

```
POST /a/v1/validation/runs   Body: { profile: "SMOKE" | "FULL" | "SOAK", seed?: number }
  SMOKE（≤10min，每次合并必跑）：S 规模 + 30 tick + 断言矩阵核心子集 + 不变量全集
  FULL （≤60min，每夜）：M 规模 + 365 tick 全回放 + 断言矩阵全集 + 混沌注入 + 三角色权限全息
  SOAK （手动）：L 规模 + 性能基线采集（各段耗时/内存，回归 >20% 标红）
```

1. **全隔离**：每次 run 创建一次性验证租户（`origin=VALIDATION`）→ 执行 → 报告落库 → 租户销毁；与演示/真实租户零交叉（复用 FORGE 闸门机制）；
2. **正门红线**（继承回放编排器铁律）：VLE 只通过公开 API 注入与读取，**断言比对时才允许直读 DB**（读不写）；静态检查：VLE 代码不 import 任何被测 service/repo；
3. **报告**：`validation_runs(id, profile, seed, started, finished, report JSONB)`——report = 七段 × 断言点的 `{pass, expected, actual, diff}` + 覆盖率三指标（§5）+ 性能基线对比；前端 `/admin/validation`：运行历史、段级红绿矩阵、失败项 diff 下钻、一键以同 seed 复跑单段；
4. **CI 契约**：SMOKE 红 → 合并阻断；FULL 红 → 次日站会首项（通知中心定向 catalog_admin）。

## 5. 工程验证度的量化定义（取代主观评分）

```
模块覆盖率 = 已自动化的 PRD 验收用例数 ÷ 全部验收用例数（基线 Part A 锚点为分母，当前 ≈180 条）
断言覆盖率 = 断言矩阵实现数 ÷ 注册表登记数
闭环覆盖率 = 七段全绿的 profile 数 ÷ 3
工程验证度 = 0.5×模块 + 0.3×断言 + 0.2×闭环   （VLE 报告首页常驻此分数及趋势）
```

发布纪律：**工程验证度纳入版本发布门禁**——平台版本发布要求 SMOKE 100% + FULL ≥98%（豁免项需 OPEN_QUESTIONS 记录原因与期限）。

## 6. 边界声明（VLE 验证什么、不验证什么）

| 验证 | 不验证（归属） |
|---|---|
| 全链路工程正确性、确定性、幂等、权限、降级、性能回归 | 业务参数的真实世界有效性（爬坡曲线是否符合某真实工厂——归 G3 真数据试点） |
| 系统对 agent 输出的**处理**正确性（溯源校验/预算/降级/审计） | agent 回答本身的质量（归评测体系 OC2——VLE 的 QOS 段用录制 Mock，刻意排除 LLM 随机性） |
| 校准回路的机制有效性（注入已知偏差→收敛） | 校准在真实噪声数据上的统计表现（归上线后 M11 元闭环） |
