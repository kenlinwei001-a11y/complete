## 取证附录（原始测量，不计正文字数）

### A · 订单簿（全簿实测，非外推）
`GET /a/v1/objects?type=Order&page=1&pageSize=500` → **500 单**
- Σ`value` = **50,725,911,442 元 = 507.26 亿元** · Σ`qty` = **2,421,222 套** · 均价 **20,951 元/套** · 单均 **1.0145 亿元**
- **客户 = 20**（真值）；集中度：广汽埃安 **223.3 亿 = 全簿 44%** · 小鹏 88.2 亿 · 长安 20.2 亿
- 基地敞口（按单值均摊）：常州 **140.1 亿 = 27.6%** · 金华 69.2 · 成都 67.4 · 枣庄 62.0
- 状态：`OPEN 50 · IN_PRODUCTION 100 · COMPLETED 350`

**单位自证**（回应"是不是万元量级"）：`value == qty × unitPrice` 在 **500/500 单上逐单相等，零例外**。`unitPrice ≈ 20,951` 只有读作**元/套**才是电池包的合理单价（读作万元/套 ⇒ 2 亿元一套，荒谬）⇒ **`value` 单位是元，Σ = 507.26 亿元**。

**分页金丝雀**（同法对照，证明不是"库里只有 N 条"）：
| 查询 | items | total |
|---|---|---|
| `?type=Order` | 50 | 500 |
| `?type=Order&limit=1000` | **50** | 500 |
| `?type=Order&page=1&pageSize=500` | **500** | 500 |
| `?type=OrderLine` | 50 | 873 |
| `?type=OrderLine&page=1&pageSize=500` | **500**（被 pageSize 截，非总量） | 873 |

⇒ `limit` 被静默忽略、回落默认页长 **50**；**50 是默认值不是上限**。
⚠ 并存一道 `queryObjects(…, 1000)` 硬顶：超过 1000 条的类型（如 `EquipmentOEE` 真实 5,460）会被**静默低估**，敞口表若用到这类类型必须另计。
