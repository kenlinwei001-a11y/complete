# COMPLETION-LEDGER · 既定目标完成度真相表（零遗漏度量）

> **这份文件是什么**：把平台**所有 canonical 源头里的"既定目标 / 验收点"穷举成一张可溯源的真相表**，作为"100% 完成、零遗漏"的**唯一定义与度量**。
>
> **为什么需要它**：本项目反复踩"绿测试≠能用 / 看着像完成实则三四成"的坑（最近一次：推演沙盘我判过"✅可合/全闭"，真实拍只有 30-40%）。根因是**每次"完成"都对着代理目标（测试绿/代码在/PRD 的 DoD）验，不是对着真实目标（端到端能用 + 竞品对标）验，且从没逐条亲手跑**。没有这张表，"零遗漏"无从谈起。
>
> **三遍法**：① **Pass-1 枚举**（本表，已完成）——从源头抽全目标，每条带可观测验收判据；② **Pass-2 真跑定级**（进行中）——逐条起真系统、以用户身份走、取证，判 ✅真能用 / ◐部分 / ❌缺，**不认测试绿**；③ **Pass-3 烧表**——缺口入队列→开发 agent 收口→两轴复审→循环到整表全 ✅带证据。
>
> **两列状态**：`文档声称`（来自 PRD，**几乎全是"待开发/未注明"，不可信，仅备查**）｜`真跑判定`（Pass-2 结论，**这才是真相**；现几乎全 ⬜未跑，唯沙盘 ◐ 已实拍）。
