Part 3 —— Decision OS CALB Ontology + Graph Model + PostgreSQL Schema
Part 3 是整个 Decision OS 的核心。
前面：
Part 1：定义了企业世界中的对象（Object） 
Part 2：定义了企业运行中的事件（Event） 
Part 3 把这些数据变成：
一个可被 Agent 理解、推理、模拟、优化的企业数字世界。
对应 Palantir Foundry/AIP 中的 Ontology Layer。

factory table
																	CREATE TABLE factory
																	(
																	factory_id VARCHAR(20)
																	PRIMARY KEY,
																	name VARCHAR(100),
																	province VARCHAR(50),
																	capacity_gwh NUMERIC,
																	status VARCHAR(20)
																	);
production_line
																	CREATE TABLE production_line
																	(
																	line_id VARCHAR(20)
																	PRIMARY KEY,
																	factory_id VARCHAR(20),
																	process_type VARCHAR(50),
																	capacity_day NUMERIC,
																	oee NUMERIC,
																	yield_rate NUMERIC,
																	FOREIGN KEY(factory_id)
																	REFERENCES factory(factory_id)
																	);
equipment

定义：
Xf,p,c,tX_{f,p,c,t}Xf,p,c,t​ 
含义：

目标函数
最大化：
Profit=Revenue−Cost−PenaltyProfit = Revenue-Cost-PenaltyProfit=Revenue−Cost−Penalty 
展开：
max∑Xf,p,c,t(price−cost)−RiskPenaltymax \sum X_{f,p,c,t} (price-cost) - RiskPenaltymax∑Xf,p,c,t​(price−cost)−RiskPenalty 
约束1：产能约束
∑Xf,p,c,t≤Capacityf,p,t\sum X_{f,p,c,t} \le Capacity_{f,p,t}∑Xf,p,c,t​≤Capacityf,p,t​ 
含义：
工厂生产不能超过产能。
约束2：订单满足
∑Xf,p,c,t≥Demandc,p,t\sum X_{f,p,c,t} \ge Demand_{c,p,t}∑Xf,p,c,t​≥Demandc,p,t​ 
约束3：物料约束
BOM：
Materialneed=X×BOMMaterial_{need} = X \times BOMMaterialneed​=X×BOM 
必须：
Materialneed≤Supply+InventoryMaterial_{need} \le Supply+InventoryMaterialneed​≤Supply+Inventory
